Bundled lsd (LSDeluxe) binaries for Glacier Terminal
=====================================================

These are unmodified prebuilt binaries from the lsd project:
  https://github.com/lsd-rs/lsd

Version: v1.2.0
License: Apache-2.0 (see LICENSE)

lsd-aarch64-apple-darwin  -- Apple Silicon (arm64)
lsd-x86_64-apple-darwin   -- Intel (x86_64)

Glacier extracts the correct binary on first launch to:
  ~/Library/Application Support/com.glacier.app/bin/lsd

This lets `ls`, `ll`, and `la` show file icons out of the box
with no additional installs required.
